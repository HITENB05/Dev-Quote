# Contributing to DevQuote

Please refer to the comprehensive [CONTRIBUTING.md](./CONTRIBUTING.md) guide for full instructions on how to contribute snippets directly via code and GitHub Pull Requests.

### Quick Summary

1. Create a JSON file in `data/snippets/<id>.json`.
2. Follow the schema defined in [CONTRIBUTING.md](./CONTRIBUTING.md).
3. Do not include any emojis in the snippet content or titles.
4. Run `npm run build:data` to update `data/snippets.json`.
5. Open a Pull Request on GitHub.
